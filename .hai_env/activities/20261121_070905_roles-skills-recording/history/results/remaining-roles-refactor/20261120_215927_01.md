## Independent skills

The root skills collection now contains:

- crete-design-package, unchanged and preserved as an uninstalled source package.
- quality-verification, retained because developer self-checks and independent QA
  genuinely share the same verification method.

The environment has the quality-verification skill installed. Its inputs are the
subject/version, agreed criteria, authorized scope, available tools, actual
independence context and optional output destinations. Its outputs are observed
criterion-to-evidence results, reproducible defects and explicit coverage limits.
It requires no HAI role, Activity, configuration file or framework directory.

QA's procedure supplies the HAI context and hands results to the host/runtime.
The skill neither changes product implementation nor grants acceptance authority.
Independent review remains an actual execution property, not a claim obtained by
selecting a skill. No speculative new skills were created.
