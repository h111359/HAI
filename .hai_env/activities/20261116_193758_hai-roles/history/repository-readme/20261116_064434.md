# HAI

HAI helps you work with AI on software and other projects. It gives your AI
tool instructions for planning, doing and checking work, and keeps the results
organized in your project.

## What can it do?

- Help turn an idea into clear requirements and a plan.
- Support development, review and documentation.
- Coordinate specialist AI agents through repeatable steps.
- Keep requests, decisions and results so you can continue work later.

## What do you need?

- **An AI coding tool:** an application where you can chat with AI about your
  project. It must be able to open your project folder, read and edit files, and
  run commands with your permission. You need access to the AI service used by
  that application; HAI does not provide the AI itself.
- **Python 3.11 or newer**, installed on your computer and accessible to that tool.
- **A project folder** where you want to use HAI.

You do not need Git to install HAI.
The core uses Python's standard library, so no extra Python packages are required.

## Install and start

1. Open the [latest HAI release](https://github.com/h111359/HAI/releases/latest).
2. Under **Assets**, download the HAI release ZIP.
3. Extract it and copy the complete `.hai` folder and `LICENSE` into your project
   folder. Make sure the hidden `.hai` folder is included.
4. Open your project in your AI coding tool and ask:

   > Set up HAI in this project by following `.hai/start.md`, then help me get started.

5. Describe what you want to do. You can also ask **"Help with HAI"**.

Specialist agents are optional and installed separately. For those steps, existing
HAI projects and upgrades, see [the installation guide](INSTALL.md).
