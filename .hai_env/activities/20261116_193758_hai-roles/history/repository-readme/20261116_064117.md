# HAI

HAI helps you work with AI on software and other projects. It gives your AI
assistant instructions for planning, doing and checking work, and keeps the
results organized in your project.

## What can it do?

- Help turn an idea into clear requirements and a plan.
- Support development, review and documentation.
- Coordinate specialist AI agents through repeatable steps.
- Keep requests, decisions and results so you can continue work later.

## What do you need?

- **Python 3.11 or newer**, installed and available to your AI assistant.
- **An AI assistant that can read and edit project files and run commands.**
  Access to its AI models is provided by your chosen tool, not by HAI.
- **A project folder** where the assistant has permission to work.

Git is optional for downloading HAI; you can also download the repository as a ZIP.
The core uses Python's standard library, so no extra Python packages are required.

## Install and start

1. Download this repository and extract it, or clone it with Git.
2. Copy the complete `.hai` folder and `LICENSE` into your project folder.
   Make sure the hidden `.hai` folder is included.
3. Open your project in your AI assistant and ask:

   > Set up HAI in this project by following `.hai/start.md`, then help me get started.

4. Describe what you want to do. You can also ask **"Help with HAI"**.

Specialist agents are optional and installed separately. For those steps, existing
HAI projects and upgrades, see [the installation guide](INSTALL.md).
