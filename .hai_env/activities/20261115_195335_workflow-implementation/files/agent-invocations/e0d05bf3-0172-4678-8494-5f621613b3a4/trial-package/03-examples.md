# Fictional examples and records

Every person, item description, date, outcome and policy selection here is invented for illustration, not a real booking or established policy. Only the quantities 20 items and two coordinators come from the brief.

For these examples only, imagine D01 allows adult residents of an organizer-defined neighborhood by self-declaration; D02 uses one contact route and first eligible request received; D03 allows one-week loans with Saturday 10:00-12:00 handovers at a fictional community room. These choices remain unapproved. Other D choices remain unresolved; no charges are assumed.

## E01: normal loan and handoff

Maya and Sam are the fictional coordinators. Alex Example requests ITEM-07 on 16 November 2026 for collection Saturday 21 November and return Saturday 28 November. Maya records eligibility under the imagined example rule and checks the item is available.

Item entry: `ITEM-07 | drill | fictional group owns item | case, charger | working, scratched case | fictional community-room cupboard | reserved for R001`.

| Loan field | Representative contents |
| --- | --- |
| Identifier / contact | R001 / Alex Example, alex@example.invalid |
| Received / eligibility | 16 November 2026 09:00 / eligible by self-declaration, checked by Maya |
| Item/accessories | ITEM-07 drill, case and charger |
| Requested/confirmed Saturdays | Collection 21 November 2026; return 28 November 2026 |
| Actual collection/return | Not yet / not yet |
| Status / possession | Confirmed / fictional group |
| Collection/return condition | Pending inspection / not yet |
| Terms acceptance | Fictional terms T-example-1 acknowledged in confirmation reply |
| Handling coordinator / next action | Maya / collection check on 21 November |
| Incident | None |

Fictional confirmation: “R001 confirms ITEM-07 drill, case and charger. Collect Saturday 21 November 2026, 10:00-12:00 at the community room; return Saturday 28 November at the same place/hours. Check the item with a coordinator; report delay, damage or missing parts through the group contact. The attached T-example-1 contains the agreed borrowing terms. No online payment is requested.” This abbreviated example lacks real approved terms, contact and venue and is not an actionable borrower agreement.

On 21 November Maya and Alex inspect the drill, note the existing scratch and complete accessories, and update R001: actual collection 21 November, on loan, possession Alex, condition working with scratched case. Alex receives a receipt containing these facts, R001, the agreed return arrangements and contact route.

Maya hands over to Sam through the proposed shared record: R001, Alex's contact, ITEM-07/accessories, collection condition, accepted T-example-1, due Saturday 28 November 10:00-12:00 at the community room, no incident, Sam to inspect return. Sam receives usable access to the loan entry, item list, confirmation and terms, not an inaccessible reference. D05 must establish the real shared location before this is practicable.

On 28 November Sam receives all parts, records actual return 28 November, condition unchanged, possession group and status returned. Receipt: “R001, ITEM-07 drill/case/charger received 28 November 2026; scratched case unchanged; no incident noted; Sam.” Following the proposed assessment, the item becomes available. Records remain subject to the unselected retention policy.

## E02: missing charger and correction

This is an alternative ending to E01, not a simultaneous second history. On 28 November Sam receives the drill and case, but no charger. Alex says the charger is at home. Sam records actual receipt of the drill/case, possession split between group and Alex, and R001 returned with incomplete accessories; incident I001 remains open. The receipt lists what arrived and what is missing. ITEM-07 becomes unavailable. No charge is demanded.

| Incident field | Representative contents |
| --- | --- |
| Reference | I001 / R001 / ITEM-07 |
| Report and observation | 28 November 2026, Sam: drill/case received, charger absent |
| Borrower account / possession | Alex reports charger at home; group holds drill/case, Alex holds charger |
| Action / coordinator | Sam to arrange Saturday 5 December return; organizer considers further action if unresolved |
| Affected booking | R002, Jordan Example, jordan@example.invalid; confirmed 28 November to 5 December |
| Notice | Sam informs Jordan before collection: unavailable; offers later Saturday or cancellation |
| Decision / money | No responsibility decision; no charge requested; D04 unresolved |
| Next action / status | Charger expected 5 December; item unavailable; incident open |

Jordan cancels. Sam records R002 cancelled because equipment is unavailable; no actual collection or loan is recorded. If Sam is away on 5 December, Maya gets I001, both loan entries, contacts, condition, terms and next action from the shared record before taking over.

On Monday 30 November Alex asks to return the charger. Sam confirms Saturday 5 December instead, preserving Saturday-only returns. Maya receives it that Saturday and records condition and possession. After the proposed assessment the item becomes available. The organizer records I001 resolved through accessory return, no damage observed, no charge requested. This outcome does not establish a blanket waiver for future loss.

Correction example: if Sam initially entered that the charger arrived on 28 November, the dated correction says “Sam, 28 November: accessories received changed from drill/case/charger to drill/case; charger absent; I001 opened; corrected acknowledgment sent to Alex.” Both coordinators can see the earlier value and reason. Merely issuing a receipt would not establish that its contents were accurate.
